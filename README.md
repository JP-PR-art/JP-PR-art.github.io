# jp-site

Personal site of Juan Pablo Perez: builds, notes, and background.
Built with [Astro](https://astro.build), styled with hand-written CSS, deployed to GitHub Pages
via Actions. Content lives in `src/content/` as markdown collections.

- `npm run dev` local dev server
- `npm run build` production build to `dist/`
- `npm run check:links` build + broken-link check
